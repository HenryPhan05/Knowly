# 📚 Knowly – Study Planner App

**Knowly** is a cross-platform mobile application designed to help users manage their study tasks, track progress, and build effective learning habits. Built with **React Native and Expo Router**, the app focuses on performance, simplicity, and a smooth user experience.

---

## 🚀 Features

* 📅 **Task Management**
  Create, update, and delete study tasks بسهولة

* 📊 **Progress Tracking**
  Monitor your learning progress over time

* 🔔 **Haptic Feedback**
  Enhance user interaction with tactile feedback

* 🌐 **Cross-platform Support**
  Runs on **iOS, Android, and Web**

* 🎨 **Modern UI & Icons**
  Built with `@expo/vector-icons` and `lucide-react-native`

* 🧭 **Navigation System**
  Powered by **Expo Router** and **React Navigation**

---


